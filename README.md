## Приложение для анализа транзакций, которые находятся в Excel-файле. Приложение генеририрует JSON-данные для веб-страниц и формирует отчет.

Который включает в себя набор модулей и функций:

* views.py - функция для генерации JSON-ответов. Данные для анализа и вывода на веб-страницах — это данные с начала месяца, на который выпадает входящая дата, по входящую дату. Принимает на вход строку с датой и временем в формате 
YYYY-MM-DD HH:MM:SS и возвращающую JSON-ответ со следующими данными:
Приветствие в формате 

 — «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» в зависимости от текущего времени.
По каждой карте:
последние 4 цифры карты;
общая сумма расходов;
кешбэк (1 рубль на каждые 100 рублей).
топ-5 транзакций по сумме платежа.
Курс валют.
Стоимость акций из S&P500.

* utils.py - содержит функции чтения файлов, сортировки данных по дате операции и отбор топ-5 транзакций по сумме платежа, а так же запрос курсов валют и стоимость акций в зависимоти от настроек пользователя.


* services.py - Функция поиска по телефонным номерам. Функция возвращает JSON со всеми транзакциями, содержащими в описании мобильные номера.


* reports.py - содержит функцию формирования отчета "Траты по категории" по операциям. Принимает на вход:

датафрейм с транзакциями,
название категории,
опциональную дату.
Если дата не передана, то берется текущая дата.
Функция возвращает траты по заданной категории за последние три месяца (от переданной даты) и записывает их в файл report.json.


### Использование

Для запуска модулей используйте main.py.


### Тестирование

Проект покрыт юнит-тестами которые находятся в папке tests. Для их запуска выполните команду:
```
pytest --cov=src --cov-report=html
```
